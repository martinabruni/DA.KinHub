## Navigation

The floating navigation bar stays fixed at the bottom and opens Home and Settings. The Information menu groups Release notes, Version, and the User guide. When a page registers contextual actions, you can swipe between the global bar and the page bar without losing position or focus.

Home no longer shows hardcoded cards. When you are signed out, you only see the introductory message and use the global shell Sign in action. With a valid session but no family yet, Home shows onboarding to create the first family. When you already belong to a family, Home reads only the active services authorized for that family from the server and renders them as dynamic cards.

## Language and theme

Choose Italian or English and a light, dark, or system theme. Preferences stay on this device and are applied before rendering to avoid a wrong-theme flash.

## User guide

Open the Information menu in the floating bar to reach the User guide, Release notes, and the Version page directly. The guides remain bilingual and are updated together with the app's visible flows.

## Family service catalog

The Home catalog is not stored in local cache: language changes, account changes, sign-out, offline state, session expiration, or family changes immediately clear the current cards and trigger a new server-side read. When the family has no active services, Home shows an empty state that stays distinct from denied access.

## Tutorial and lifecycle

The tutorial starts on first launch, can be skipped, and can be restarted from Settings. Version and Release notes explain KinHub's evolution: each feature comes with translations, documentation, tests, and release notes.
