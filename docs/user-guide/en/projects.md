## Create a project

Enter a name between 3 and 120 characters and select **Create**. The name is normalized and must be unique. Validation errors are shown without losing the form contents.

## Stages

A project starts in Discovery and can advance to Planning, Delivery, and Completed. The domain prevents accidental regressions.

## Access and limits

When Microsoft Entra External ID is configured, this area requires sign-in and the API scope. Authentication may be disabled in local development. The initial version provides creation and listing; editing and archiving will arrive as versioned features.
