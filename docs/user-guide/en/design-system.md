# Design system

This temporary page collects the proposed primitives and patterns for the KinHub interface.

## Explore the components

Interact with buttons, fields, menus, dialogs, drawers, and snackbars to review their states and animations. The floating bar carousel supports touch, horizontal swiping, indicators, and keyboard arrow keys.

## Themes and accessibility

Components work in light and dark themes, preserve a visible focus, and honor the device's reduced-motion preference.

## Limitations

Examples use demonstration data and do not save information. The page will be removed after approval and integration of the design into the actual routes.
