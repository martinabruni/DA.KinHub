title: Version and build
description: Identify the KinHub version and its build metadata.
---

KinHub uses Semantic Versioning. The Version page shows the application version, commit SHA, build date, and environment. These values make a problem report precise and confirm that an update has arrived.

The same version comes from the root `VERSION` file and is included in the backend assembly, frontend bundle, `/api/version` endpoint, ZIP package, and release notes. Local builds may use development markers for commit and date.
