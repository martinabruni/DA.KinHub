title: Versione e build
description: Identificare la versione di KinHub e i relativi metadati.
---

KinHub usa Semantic Versioning. La pagina Versione mostra versione applicativa, commit SHA, data build e ambiente. Questi dati consentono di descrivere con precisione un problema e verificare che un aggiornamento sia arrivato.

La stessa versione nasce dal file `VERSION` ed entra in assembly backend, bundle frontend, endpoint `/api/version`, pacchetto ZIP e note di rilascio. In locale commit e data possono usare marcatori di sviluppo.
