# Richiesta di modifica

Una CR deve rendere espliciti comportamento attuale e desiderato, impatto utente, dati, sicurezza, operazioni, compatibilità e rollback. Aggiorna gli stessi artefatti previsti dalla Definition of Done.

Per una feature esistente conserva `feature.md` e rinomina il suo piano originario in `feature.plan.md`. Aggiungi `cr.md` per il delta approvato e `cr.plan.md` per l'esecuzione, senza riscrivere retroattivamente requisiti o piano della consegna precedente.
