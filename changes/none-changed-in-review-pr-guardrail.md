## it
Reso esplicito nell'harness che portare una feature a `In review` richiede sempre commit e push su `dev`, pull request aperta verso `main` e tutte le GitHub Actions verdi sull'ultimo SHA prima di considerare conclusa la consegna.

## en
Made the implementation harness explicit that moving a feature to `In review` always requires commit and push on `dev`, an open pull request to `main`, and green GitHub Actions on the latest SHA before delivery can be considered complete.
