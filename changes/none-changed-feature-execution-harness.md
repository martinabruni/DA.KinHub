## it

Aggiornato l'harness con esecuzione autonoma delle feature fino alla Definition of Done, checkpoint riprendibili solo per soglia del contesto o human in the loop e consegna tramite pull request senza merge. Le GitHub Actions della PR devono essere tutte verdi sull'ultimo commit; ogni run rosso richiede diagnosi, correzione e nuovo push.

## en

Updated the harness with autonomous feature execution through the Definition of Done, resumable checkpoints only for the context threshold or human-in-the-loop needs, and pull request delivery without merging. Every pull request GitHub Action must be green on the latest commit; each red run requires diagnosis, a fix, and another push.
